# ビジュアルタイマー

メモリが減っていく見た目で、残り時間がひと目でわかるタイマーです。HTML 1 枚で動き、インストールは要りません。

https://l1lyhub.github.io/visual-timer/

## できること

- 通常モード: 1〜180 分のタイマー
- 繰り返しモード: A（作業）と B（休憩）を交互に、止めるまで繰り返す。休憩中はメモリが逆向きに増えていく
- メモリの本数は画面の大きさで決まり、設定した時間で減る速さが変わる
- ライト／ダーク表示。設定は次に開いたときも残る
- キー操作: `Space` スタート／一時停止、`R` リセット

## スマホで使う

- iPhone（Safari）: 共有ボタン →「ホーム画面に追加」
- Android（Chrome）: メニュー →「ホーム画面に追加」（または「アプリをインストール」）

ホーム画面から開くと、アドレスバーのない画面で開きます。

- 実行中は画面が消えないようにしている（対応しているブラウザのみ）
- 画面を消したり、別のアプリに切り替えたりしている間は音が鳴らない。戻ると、その時点の正しい残り時間・区間から続く
- iPhone は消音モードのときは音が鳴らない

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体（HTML・CSS・JavaScript をこの 1 枚にまとめている） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン・表示のしかた |
| `icons/` | ホーム画面用のアイコン |
| `.nojekyll` | GitHub Pages でファイルをそのまま公開するための空ファイル |

## GitHub Pages で公開する

リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` と `/ (root)` にして Save。数分で上の URL で開けるようになる。
